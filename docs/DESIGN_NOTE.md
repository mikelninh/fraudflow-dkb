# Design note

FraudFlow uses a calm blue/white visual direction inspired by the public DKB digital experience, but it is an independent role-specific work sample.

It does **not** use the DKB logo, claim to be an official DKB product, or copy protected brand assets. The interface keeps an explicit independent-work-sample label.

A commonly cited approximation for DKB blue is `#148DEA`; this is treated here as a visual reference, not as an official brand-guideline claim.
